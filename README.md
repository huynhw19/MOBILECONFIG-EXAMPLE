A curated collection of example Apple configuration profiles for iOS devices.

## Overview

This repository contains example `.mobileconfig` files, including:

- Wi-Fi configuration examples
- Mail and account setup examples
- DNS profile examples
- Beta profile examples
- Security and hardening examples
- Community-shared profiles

## 🚀 Features

- DNS profile samples
- Beta profile samples
- Secure profile examples
- Community discussions and shared profiles
- Simple install guidance for iPhone and iPad

## 📁 Repository Layout

- `Example1.mobileconfig` — basic Wi‑Fi profile example
- `Mailbox1.mobileconfig` — Mail / CalDAV / CardDAV profile example
- `Community/` — community submitted profiles
- `IOS hardening/` — hardening-focused examples
- `UDID/` — UDI-related profile examples
- `Web clip/` — web clip examples
- `Zip/` — zipped profile-related examples
- `folder_dns/` — DNS profile examples
- `folder_apps/` — app-related configuration samples

## 🛠️ How to install

1. Download the profile to your device.
2. Open the `.mobileconfig` file.
3. If prompted, open Settings.
4. Go to General > VPN & Device Management.
5. Tap the profile and review the details.
6. Confirm whether the profile is signed and trusted.
7. Tap Next.
8. Read any warning message.
9. Tap Install.
10. Enter your passcode.
11. Review the warning carefully and continue only if you understand the risk.
12. Tap Install again and wait for setup to finish.
13. Once complete, the device settings will have changed.

## ⚠️ Warning

Profiles may be unsigned, experimental, or built for older iOS versions. Only install profiles from trusted sources and only if you understand the risk. An untrusted configuration profile may affect network access, device behavior, or privacy.

## 🧭 Notes

- This repository is intended for educational and testing use.
- These are example files and may require modification before production use.
- Apple devices may require valid certificates or signed payloads for full functionality.

## 🔒 Suggested Use

Use these files as references or templates only. Replace placeholder values such as hostnames, usernames, and passwords before using them on a real device.
